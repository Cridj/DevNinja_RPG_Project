# DevNinja RPG Project

Unity로 제작한 RPG 프로젝트입니다.  
게임 시스템과 UI, 데이터 처리 기능을 구현하며 Unity와 C#을 학습한 내용을 담고 있습니다.

## Tech Stack

![Unity](https://img.shields.io/badge/Unity-2021.2.10f1-000000?style=flat-square&logo=unity)
![C%23](https://img.shields.io/badge/C%23-239120?style=flat-square&logo=csharp&logoColor=white)

## Project Overview

- Unity 기반 RPG 프로젝트
- TextMesh Pro를 활용한 UI 구성
- CSV Serializer를 이용한 게임 데이터 처리
- DOTween을 활용한 애니메이션 및 연출 구성

## Getting Started

1. 저장소를 클론합니다.
2. Unity Hub에서 프로젝트 폴더를 엽니다.
3. Unity `2021.2.10f1` 버전으로 실행합니다.

> 개인 학습 및 포트폴리오 목적으로 제작한 프로젝트입니다.
